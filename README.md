# 💧 EcoÁgua: Classificador de Consumo Residencial e Comercial

## 🚀 Sobre o Projeto
Este script em Python foi desenvolvido para auxiliar a companhia de saneamento a classificar o perfil de consumo dos clientes, fornecendo feedbacks imediatos e educativos com base no tipo de imóvel e no volume gasto em **10 m³** ou **25 m³**.

## 🛠️ Como Executar
1. Certifique-se de ter o **Python 3.x** instalado.
2. Clone este repositório ou baixe o arquivo `vinicius_Ag7_DS_I`.
3. Execute o comando no terminal:
   ```bash
   python app.py
